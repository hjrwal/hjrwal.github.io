🧠 SRS 间隔复习

艾宾浩斯式分级调度，错词按间隔重新出现，掌握后自动移出错题本。

// 间隔天数（天）
REVIEW_INTERVALS = [1, 2, 4, 7, 15, 30]
due = today + INTERVALS[stage]
if stage >= len: 移出错题本

⚡ SW 缓存失效策略

安装即接管页面，资源更新后自动刷新，根治 PWA「常驻不重启」老问题。

install → skipWaiting()
update  → controllerchange
        → location.reload()

🔊 TTS 降级方案

设备缺失语音引擎时，用 edge-tts 预录本地音频优先播放，失败则静默降级。

speak(text):
  if AUDIO_MAP[text]:
      play(local_mp3)
  else: webTTS(text)

🎯 双维度弱项诊断

按单元统计错次（热力色阶）+ 掌握度（进度条），精准定位薄弱环节。

weakByUnit[unit] = {
  sel, spell, sent   // 错题计数
}
master = solved / total // 进度条
