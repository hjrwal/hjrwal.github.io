🧠 SRS 间隔复习

艾宾浩斯式分级，错词按间隔重新出现，掌握后移出错题本。

REVIEW_INTERVALS =
[1, 2, 4, 7, 15, 30]  // 天
due = today + interval[stage]

⚡ SW 缓存失效

安装即接管，资源更新后自动刷新，根治 PWA 常驻不重启。

install → skipWaiting()
update → controllerchange
       → location.reload()

🔊 TTS 降级

系统缺语音引擎时，edge-tts 预录本地音频优先，静默降级。

speak(text):
  if AUDIO_MAP[text]
     → play(mp3)
  else → webTTS(text)
